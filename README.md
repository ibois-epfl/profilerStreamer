# profilerStreamer
profilerStreamer is a small project to combine 2D laser profiler data with 1D sick distance sensor to recreate 3D point cloud of timber pieces in a CNC.

## Usage
### UV
We use [`uv`](https://docs.astral.sh/uv/) as package manager. Please  [install `uv`](https://docs.astral.sh/uv/) before trying to run.
